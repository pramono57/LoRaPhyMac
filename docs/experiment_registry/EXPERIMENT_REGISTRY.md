## Keputusan lineage R1.7

Sejak keputusan penelitian 1 November 2026, **`apc_load_sweep` adalah implementasi resmi R1.7**. Grid produksi yang berlaku berjumlah 120 run dan sudah tervalidasi pada latest runner: FF 60/60, AA 60/60 PASS. Load profile 90-run dalam `scalability_relay_bottleneck` berstatus legacy/deprecated. Package scalability tetap aktif untuk Pilot dan Relay Duty. Lihat [audit deprecasi legacy R1.7](LEGACY_R1_7_DEPRECATION_AUDIT.md).
