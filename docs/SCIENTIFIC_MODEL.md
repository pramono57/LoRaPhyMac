# Scientific model notes

This document records correctness-sensitive assumptions that affect the
interpretation and reproduction of LoRaPhyMAC results.

## Finite observation horizon

`run_single_simulation()` stores the hard simulation boundary in
`env.simulation_end`. Radio and optional MCU energy are integrated only over
the part of each sleep, transition, TX, or end-device RX state that lies inside
that boundary.

A physical transmission may start before the boundary and end after it. Its
packet fate remains right-censored, while energy and utilization include only
the observed part. This prevents sleep or airtime scheduled beyond the run
from inflating energy totals.

## Receiver RF domain

`Packet.next_hop` identifies the intended logical receiver; it does not define
the complete RF domain. Every transmission is copied to all registered relay
and gateway receivers except the transmitter itself. Each receiver calculates
its own propagation delay, path loss, RSSI, feasibility, demodulator admission,
and collision outcome.

A receiver-local copy whose `next_hop` identifies another receiver participates
as an interferer but cannot be forwarded, delivered, or recorded as a terminal
packet fate. This preserves packet-fate conservation while allowing hidden and
inter-receiver interference.

End-device `NodeRX` currently receives only its intended physical downlink.
Receiver-wide collision handling for simultaneous end-device downlinks is not
yet implemented and must be treated as a model limitation.

## PHY feasibility and collision

- Link feasibility is based on sensitivity plus the configured feasible
  margin. SNR is reported as a diagnostic and can optionally constrain
  `max_distance()`.
- The collision engine evaluates time and spectral overlap at each receiver.
- The configured pairwise capture/SIR model is an analytical abstraction; it
  is not a complete LoRa preamble-lock or aggregate-interference waveform
  model.
- ITM uses area mode and clamps distances below 1 km to its supported minimum.

## Result compatibility

Results generated before receiver-wide RF broadcast and finite-horizon energy
clipping are not scientifically equivalent to results generated by this
version. Paper-level multi-seed experiments must be rerun after the code and
experiment configuration are frozen.
